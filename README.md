# 🏨 Hotel Management System

A simple web application to manage hotel details using ReactJS, Redux, Node.js, Express.js, and PostgreSQL.

## Features
- Add, edit, and delete hotels
- Search and filter hotels
- View hotel details
- Upload hotel images
- Responsive design

## Technologies
- ReactJS
- Redux
- Node.js & Express.js
- PostgreSQL

## Purpose
Developed as a learning project to understand full-stack web development and CRUD operations.
